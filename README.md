# E-commerce Sales & Delivery Analysis (Olist)

End-to-end analysis of an online marketplace using **PostgreSQL**, **Python (Pandas, Matplotlib, Seaborn)** and **Power BI (DAX)**.

## Business Questions
1. How does monthly revenue trend, and which product categories drive it?
2. Do late deliveries lead to lower customer review scores?
3. What share of customers place more than one order?
4. Which sellers perform best and worst?
5. Where are delivery delays worst (by state)?

## Dataset
Brazilian E-Commerce Public Dataset by Olist (Kaggle). The raw CSV files are not stored in this repo. Download them from Kaggle and place them in the `data/` folder.

## Tools
PostgreSQL | Python (Pandas, Matplotlib, Seaborn) | Power BI, DAX | GitHub
